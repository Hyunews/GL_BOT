# 🏆 디스코드 길드리그 참석투표 봇 (Discord Guild League RSVP Bot)

디스코드 길드원들의 길드리그 참석투표를 효율적으로 관리해 주는 다중 서버 지원 디스코드 봇입니다.

## ✨ 주요 기능

1. **시간대별 다중 투표 생성 (`/투표생성`)**
   - 예: `8/4 19:00`, `8/4 20:00`, `8/4 21:00` 등 쉼표 한 번으로 여러 시간대 선택지 자동 생성
2. **직관적인 인터랙티브 버튼 투표**
   - `[참석: 8/4 19:00]`, `[참석: 8/4 20:00]`, `[🔴 불참]`, `[🟡 미정/대기]` 버튼 제공
   - 클릭 시 실시간 현황 업데이트 및 명단 자동 정렬
3. **멀티 서버 (Multi-Guild) 완벽 지원**
   - 초대 링크 하나로 다른 디스코드 서버 운영진이 가져다 써도 독립적인 투표 운영 가능
4. **무료 클라우드 24/7 배포 호환**
   - Render.com / Koyeb + Supabase / Neon PostgreSQL 지원
   - Express 헬스체크 포트 내장으로 UptimeRobot 연동 시 365일 24시간 무과금 항시 가동

## 🚀 빠른 시작
